# freellm-chat

یک کلاینت چت **ترمینالی** کوچک برای [FreeLLMAPI](https://github.com/tashfeenahmed/freellmapi).
فقط به Python 3 نیاز دارد و هیچ پکیج اضافه‌ای نصب نمی‌شود.

با FreeLLMAPI روی سیستم خودتان اجرا شده، این برنامه به آدرس محلی آن وصل می‌شود، جواب را به‌صورت **استریم** نشان می‌دهد و تاریخچهٔ گفتگو را در همان نشست نگه می‌دارد. بعد از هر پاسخ هم می‌بینید کدام سرویس و مدل آن را داده است (هدر `X-Routed-Via`).

> این یک ابزار شخصی و آزمایشی است. مدل‌های رایگان محدودیت و نوسان دارند و این پروژه مدل Claude را رایگان نمی‌کند.

## پیش‌نیاز

1. Python 3.8 یا بالاتر
2. FreeLLMAPI نصب و در حال اجرا (پیش‌فرض: `http://localhost:3001`)
3. چند کلید رایگان که در صفحهٔ **Keys** داشبورد FreeLLMAPI وارد کرده‌اید
4. «کلید یکپارچه» (`freellmapi-...`) که همان صفحه نشان می‌دهد

## نصب و اجرا

```bash
git clone https://github.com/<your-username>/freellm-chat.git
cd freellm-chat
cp config.example.json config.json
```

فایل `config.json` را باز کنید و `api_key` را با کلید یکپارچهٔ خودتان عوض کنید. بعد:

```bash
python3 chat.py
```

روی ویندوز اگر `python3` کار نکرد، از `python chat.py` استفاده کنید.

## دستورها

| دستور | کار |
|---|---|
| `/help` | نمایش راهنما |
| `/reset` | پاک کردن تاریخچهٔ گفتگو |
| `/model NAME` | عوض کردن مدل، مثلاً `auto`، `auto:fast` یا `auto:smart` |
| `/exit` | خروج (Ctrl+D هم کار می‌کند) |

## تنظیم با متغیر محیطی

به‌جای `config.json` می‌توانید از این‌ها استفاده کنید:

```bash
export FREELLM_API_KEY=freellmapi-your-key
export FREELLM_BASE_URL=http://localhost:3001/v1   # اختیاری
export FREELLM_MODEL=auto                          # اختیاری
python3 chat.py
```

متغیرهای محیطی بر `config.json` اولویت دارند. با `FREELLM_CONFIG` هم می‌توانید مسیر فایل تنظیمات دیگری بدهید.

## امنیت

- `config.json` در `.gitignore` است تا کلید واقعی‌تان اشتباهاً در GitHub نرود.
- کلید را داخل چت، issue یا کد قرار ندهید. اگر جایی فاش شد، همان لحظه آن را باطل کنید.

## عیب‌یابی

- **Cannot reach ... Is FreeLLMAPI running؟** برنامهٔ FreeLLMAPI را اجرا کنید و آدرس و پورت را بررسی کنید.
- **HTTP 401:** کلید یکپارچه اشتباه است.
- **HTTP 429 یا خطای مدل:** سقف رایگان آن سرویس پر شده. چند لحظه بعد دوباره امتحان کنید یا کلید سرویس‌های بیشتری اضافه کنید.

## وضعیت آزمایش

این برنامه روی یک سرور آزمایشی (mock) با استریم SSE بررسی شده و درست کار کرده است. روی خود FreeLLMAPI و سرویس‌های واقعی هنوز آزمایش نشده است.
